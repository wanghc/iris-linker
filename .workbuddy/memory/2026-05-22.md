# 2026-05-22

## iris-linker 批量同步功能开发

### 功能概述
在 VSCode SCM（Git）视图标题栏新增「Sync All to IRIS Server」按钮（云上传图标），点击后将所有本地修改的 IRIS 文件批量同步到远程 IRIS 服务器。

### 详细改动

**`package.json` 变更**:
- 新增 `iris-linker.syncAllToServer` 命令（`irir-linker` 类别）
- 新增 `scm/title` 菜单贡献（`scmProvider == git` 时在标题栏显示云上传按钮）
- 新增 3 个配置项：
  - `iris-linker.sync.ignoreConflict` (boolean, default true) — 同步时忽略冲突
  - `iris-linker.sync.includeUntracked` (boolean, default false) — 包含未跟踪文件
  - `iris-linker.sync.confirmBeforeSync` (boolean, default true) — 同步前弹确认框
- 右键导出菜单 `resourceExtname` 正则扩展为 `/\.(cls|mac|int|csp|js|css|html?|png|jpe?g|gif|bmp|ico|webp|eot|otf|ttf|woff2?|pdf)$/i`

**`src/tool/tool.ts` 新增**:
- `FILE_CATEGORIES` 常量：`CLASS_FILES` / `WEB_TEXT_FILES` / `BINARY_FILES`
- `SUPPORTED_EXTENSIONS` 常量：所有支持的文件扩展名
- `isBinaryFile()` — 判断文件是否为二进制类型
- `readFileContent()` — 根据文件类型选择 UTF-8 或 Base64 编码读取
- `importDocumentToServer()` — PUT 到 Atelier API `/api/atelier/v7/{ns}/doc/{docName}`，支持 `?ignoreConflict=1`
- 文件顶部新增 `import * as fs from 'fs'` 和 `import * as path from 'path'`

**`src/extension.ts` 新增**:
- 导入 `importDocumentToServer`、`FILE_CATEGORIES`、`SUPPORTED_EXTENSIONS`
- 添加 `fs` 和 `child_process` 导入
- `getGitChangedFiles()` — 执行 `git diff --name-only HEAD` + `git ls-files --others --exclude-standard`
- `filterIRISFiles()` — 按扩展名过滤支持的 IRIS 文件
- 注册 `iris-linker.syncAllToServer` 命令：
  - 检查 Git 仓库有效性
  - 获取修改文件列表 → 过滤 → 确认 → 批量上传
  - `window.withProgress` 显示进度条
  - 汇总成功/失败结果，失败列表展示

### 文件类型支持矩阵
| 分类 | 扩展名 | 文档名格式 | 编码 |
|------|--------|-----------|------|
| 类文件 | .cls/.mac/.int | Package.Class.ext | UTF-8 |
| Web 文件 | .csp/.js/.css/.html/.htm | /path/to/file.ext | UTF-8 |
| 图片 | .png/.jpg/.gif/.bmp/.ico/.webp | /path/to/file.ext | Base64 |
| 字体 | .eot/.otf/.ttf/.woff/.woff2 | /path/to/file.ext | Base64 |
| 文档 | .pdf | /path/to/file.pdf | Base64 |

## iris-linker 批量同步 Bug 修复（两处）

### Bug 1：路径出现 `src\src` 重复
- **原因**：VSCode `wsFolder` 指向打开的子目录（如 `src`），但 `git diff --name-only` 返回相对于 Git 根目录的路径，两者拼接出现路径重复。
- **修复**：新增 `getGitRoot()` 函数（`git rev-parse --show-toplevel`），所有文件路径统一基于 Git 根目录拼接。

### Bug 2：`Invalid JSON Content`（Atelier API 规范不符）
- **原因**：`readFileContent()` 返回 `content: string`（单字符串）；但 Atelier API `PUT /doc/{name}` 要求 `content` 必须是 `string[]`（字符串数组）。
- **文本文件**：`text.split(/\r?\n/)` 逐行拆分，并去掉末尾空行（避免 CSP 文件每次保存后追加空行）。
- **二进制文件**：以 24573 字节为一块分片 Base64 编码（参照 vscode-objectscript `base64EncodeContent()`，保证每片 ≤32764 字符，低于服务器 32K 字符串限制）。
- **同时**新增 `mtime: -1` 字段（忽略冲突时间戳检查）。
- ✅ 用户确认修复成功，批量同步功能正常运行。
